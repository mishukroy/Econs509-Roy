The model and numerical definitions are in the student's `spec.md`. This folder
implements the household solvers, invariant distributions, diagnostics, and
output writers. Independent checks are in `tests/verify.py`.

From the assignment folder, with NumPy, SciPy, and Matplotlib available:

```text
python code/run_all.py --stage 2
python code/run_all.py --stage 3
python tests/verify.py --stage 3
```

The default `python code/run_all.py` reproduces validation while no method
choices exist. Later experiments require the student's prompt and choices.
Use `--part abc`, then `--part e`, `--part f`, `--part g`, and `--part h` only
as the student authorizes each part. Every part stops at its boundary.

Later `code/selected_settings.json` records these keys: `solver` (one of
`vfi`, `howard`, `modified_howard`, `gradient`, `adam`), `distribution_method`
(`power`, `eigenvector`, `equations`), `representation` (`dense`, `sparse`),
and, as the student makes each choice, `kmax`, `family` and `N`. The file is
not created before the student has chosen. No default choices are supplied.

A long call exits with code 75 after saving state under `results/.checkpoints/`.
Repeat the same command to resume; the settings must match. Checkpoints retain
values, counters, optimizer moments, traces, and elapsed time. Completed cases
in a bounded batch are recorded there as well. Checkpoint files are not committed.

All committed numerical outputs are generated by `run_all.py` or `verify.py`.
JSON files list their associated arrays, settings, counts, timings, and metrics.
Euler residual formulas are evaluated for all states so the scalar test can
inspect borrowing-boundary states; reported Euler summaries use only the
specified positive-saving mask. Distribution figures show masses, including
on nonuniform grids.

Full baseline gradient tests, final scaling checks, stage-4 output completeness,
clean-copy reproduction, and the stage-4 folder README remain pending until
the experiment prompt and student choices are supplied.
